# Shared Skills

This directory is reserved for skills that can be used by more than one agent.

Shared skills should describe reusable behavior that is not tied to a specific tool runtime.

Current shared skills:

- make-interfaces-feel-better;

Related shared scripts live in `.agents/scripts/`.

Examples of future shared skills:

- repository-intake;
- task-risk-check;
- validation-checklist;
- review-finding-format.
