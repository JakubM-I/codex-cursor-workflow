# Cursor Materials

This directory is for Cursor-specific materials.

Use it for Cursor rules, implementation prompts, editor-native configuration, and skills or references intended primarily for Cursor. Cursor is an implementation agent: Codex prepares the task contract and owns verification, review, delivery records, and task closure.

The same boundary applies to remediation packets. A remediation packet fixes one approved project-verification finding; it never authorizes Cursor to edit the verification report, remediation plan, or project decisions.

Keep shared material in `.agents/` instead.
